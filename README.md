# Sales_Analysis_Dashboard
An end-to-end data analysis project exploring sales performance.

## Project Overview
This dashboard allows team leads to explore business metrics dynamically. it loads data from a CSV file,
processes the records using **Pandas**, and renders interactive via Streamlit's native elements.

### Key Features:
* What are total revenue?
* Which product categories generate the highest Sales?
* Which regions (City) perform best?
* What are the Best product?

## Technologies Used
**Python:** Core programming language.
**Streamlit:** Framework for building the web interface.
**Pandas:** Library for data manipulation and Cleaning.

## Getting Started

### Prerequisites
*Python 3.8 or higher installed on your computer.
*Pip(Python package manager).
### Installation
1. Clone or download this repository.
2. Open your terminal or command prompt and navigate to the project folder.
3. install the required dependencies
### Running the Dashboard
1. Ensure your data file('sales_data.csv') is inside the project directory or in your computer.
2. Run the streamlit app:
   bash
   streamlit run app.py
3. Open the local URL provided in your terminalm in your web browser
